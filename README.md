# Caso de estudio

## Título
Análisis de accidentes viales en Colombia usando un Data Lake en AWS

## Descripción
Este proyecto busca construir un pipeline de datos distribuido en AWS para analizar accidentes viales en Colombia. Se integrarán datos desde archivos CSV, una base de datos MariaDB en RDS y una fuente pública mediante URL/API.

## Fuentes de datos
- Archivos CSV: accidentes viales.
- RDS MariaDB: parque automotor por ciudad/departamento.
- URL pública: datos complementarios como combustibles, clima o información geográfica.

## Objetivo
Centralizar, limpiar, transformar, consultar y visualizar datos relacionados con accidentalidad vial en Colombia usando servicios como S3, EC2, RDS, Glue, Athena, PySpark y Streamlit.




## Preguntas de negocio

1. ¿Qué ciudades presentan la mayor cantidad de accidentes viales?

2. ¿Qué meses del año registran más accidentes?

3. ¿Qué tipos de vehículos están más involucrados en accidentes?

4. ¿Existe relación entre el tamaño del parque automotor y la cantidad de accidentes?

5. ¿Qué departamentos presentan mayor crecimiento de accidentalidad a través del tiempo?

6. ¿Cuál es la tasa de accidentes por cantidad de vehículos registrados?
